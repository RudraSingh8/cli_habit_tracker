# cli_habit_tracker

> A lightweight, zero-dependency CLI habit and discipline tracker engineered in C, featuring local file persistence, automated OS date-fetching, and defensive buffer validation.

## Overview
A lightweight command-line tool built to track daily habits and log digital addiction triggers locally on a mobile device. Unlike standard GUI apps that rely on heavy frameworks, this project focuses on raw memory logic, data structuring, and persistent file storage.

## Why This Project Matters
This project proves practical command-line proficiency and low-level data handling on resource-constrained hardware. It solves a real-life discipline problem while demonstrating the core programming logic, pointers, and file operations required for modern systems and infrastructure development.
